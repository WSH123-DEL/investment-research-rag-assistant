# 研报问答助手

一个面向 PDF 研报阅读的 RAG（检索增强生成）学习项目，使用 Python 和 LangChain 相关组件，调用 DeepSeek 模型，根据用户上传的资料进行问答与分析。目前主要围绕具身智能行业研报，辅助整理公司业务、融资、估值口径及风险信息。

## 主要功能

- **PDF 资料问答**：上传一份或多份研报，提取文本、分块并建立检索索引，为模型回答提供原文依据。
- **本批文件与会话隔离**：只索引本次上传的文件；重新处理文件时清空旧知识库、聊天历史和证据展示，减少历史资料混入。不同浏览器会话分别保存知识库状态。
- **混合检索**：结合向量检索与 BM25 关键词排序，并利用文件名匹配和预设主题词扩展寻找相关内容；按字符预算组织送入模型的原文。
- **两种回答模式**：提供标准回答和深入分析。深入分析通过 API 请求开启模型思考，并增加一次对照原文的模型核查，耗时和用量通常更高；实际支持情况取决于所配置的模型与接口。
- **来源核查**：展示检索到的文件名、PDF 页码和原文，并为回答提供引用，方便回到资料中核对。

## 技术栈

Python · LangChain · DeepSeek API · Hugging Face Embeddings · Chroma · pypdf · Gradio

基本流程：上传 PDF → 文本提取与分块 → 建立索引 → 检索相关资料 → DeepSeek 生成回答 → 展示回答与来源。

## 当前状态

项目在开源示例参考和 AI 编程工具辅助下持续迭代，当前重点是理解 RAG 流程、完善文件隔离与检索逻辑。检索准确性、回答质量和 token 用量尚未完成系统的新旧版本对比评测。

扫描版 PDF 需要先进行 OCR。模型回答及自动核查可能出错，关键数字、表格和结论仍需对照原文确认。
